# Reference

The specification page is normative; the remaining pages summarize it.

| Page | Content |
| --- | --- |
| [Normative specification](specification.md) | The complete v1 contract, including the EBNF grammar that is the final authority on syntax. Generated byte for byte from `src/SPECIFICATION.md`. |
| [KORML schema](schema.md) | The declaration language: root fields, commands and shapes, flags, options, positional slots, and the four primitive types. |
| [Parser rules](parser-rules.md) | The per-level scanning procedure, option forms, occurrence limits, slot assignment, and the `--` delimiter, with pseudo-code. |
| [Portable results and conformance](results.md) | The result representation and how the conformance vectors are organized. |
| [Error codes](errors.md) | Every portable error code, where its `index` points, and a concrete `argv` that triggers it. |
| [Implementation and conformance](implementation.md) | Checklist for implementing a conforming library and the procedure for running the conformance vectors. |

!!! info "Precedence"

    If prose, schema, examples, or conformance cases contradict the EBNF
    grammar on syntactic acceptance, the grammar prevails and the
    contradiction is a specification defect. The summary pages on this site
    never add rules; they only restate the specification.
